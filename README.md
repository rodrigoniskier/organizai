# OrganizAI — Organiza Downloads

PWA offline-first para ChromeOS voltada a classificar e mover arquivos soltos da pasta Downloads para subpastas apropriadas.

## Recursos

- seleção explícita da pasta Downloads;
- análise apenas dos arquivos soltos da raiz;
- classificação por extensão, palavras-chave e regras personalizadas;
- prévia antes da movimentação;
- criação automática de subpastas;
- proteção contra sobrescrita;
- opção de ignorar arquivos recentes;
- histórico local;
- desfazer a última organização;
- funcionamento offline após a primeira carga;
- sem backend obrigatório.

## Uso no ChromeOS

1. Abra a versão publicada via GitHub Pages no Chrome.
2. Instale como aplicativo quando o navegador oferecer a opção.
3. Clique em **Escolher pasta Downloads** e conceda acesso de leitura e gravação.
4. Clique em **Analisar Downloads**.
5. Revise os destinos sugeridos.
6. Clique em **Organizar agora**.

> O navegador pode solicitar novamente a permissão da pasta após reinicializações ou mudanças de segurança.

## Privacidade

O processamento principal ocorre localmente no dispositivo. Regras e histórico permanecem no navegador.
